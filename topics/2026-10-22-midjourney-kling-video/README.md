## 技术实现

操作级流程可拆为：

1. 在 Midjourney 中创建或编辑角色参考图，确定服装、光线、构图和整体风格。
2. 需要跨镜头一致性时，选择相应版本支持的角色/对象参考功能。官方索引摘要说明 V7 使用 Omni Reference，旧 Character Reference 的适配范围不同。[S1]
3. 把选定图像作为可灵的首帧或元素参考，追加动作、运镜和场景描述。
4. 生成短片后人工选择效果，检查面部、手部、衣服和运动连续性，再剪辑成成片。[S2][S3]

## 复现路径

**根据功能资料整理，未调用付费模型、未生成视频。**

1. 先做单角色、单镜头测试；保存原图、提示词、选择的模型版本及参数。
2. 将图上传为可灵首帧，描述一个简单动作和一条运镜。
3. 使用当前模型允许的时长与画幅生成，下载结果。
4. 连续查看整个片段，核对人脸、手、服装、背景和动作；修改提示词后对比。
5. 多镜头时保持参考素材一致，逐镜验收后剪辑。

成功标准是完整片段的角色和动作可接受，而不只是某一帧漂亮。原片完全复现仍需要原视频和作者参数。

## 适用场景与限制

适合角色短片、广告概念、情绪氛围和分镜预演。生成结果有随机性，参考不能保证每一帧一致；高频动作、遮挡、多人互动和细节往往需要多次尝试。模型额度与使用权须分别按服务当时的规则核对。
