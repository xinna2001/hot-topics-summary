# 杀戮尖塔：构筑、路线取舍与动作地牢能借到什么

收录日期：2026-11-17

最近核实：2026-11-17，Asia/Shanghai

研究状态：官方玩法定位已核实；回合、节点、构筑及跨局细节用二手资料补充；未实际试玩、未阅读商业源码。

## 一句话结论

第一款游戏**不必把夜勤人式动作地牢换成卡牌战斗**。最值得借《杀戮尖塔》的是“看得懂的风险路线、互斥选择、收益与代价”，而不是把移动、翻滚、武器和潜水共用操作推倒重做。

## 技术实现

这是玩法拆解与独立实现思路，**不是对原游戏源码/类名的还原**。

### 1. 三层循环

```text
战斗内：观察敌人意图 → 按手牌和能量出牌 → 攻击/防守/强化取舍
单趟内：选地图路线 → 战斗/精英/事件/休息/商店等节点 → 修改牌组和遗物组合
跨局间：重新开始构筑 → 解锁更多内容和挑战 → 玩家积累知识
```

它的乐趣不只在“卡很多”，而在于每次拿到不完整的资源后，决定怎样把这次旅程的组合变得可靠。[S1–S5]

### 2. 四种关键决策

| 决策 | 为什么不是单纯挑最大数字 | 资料依据 |
| --- | --- | --- |
| 出牌顺序 | 能量和手牌有限；防守当前伤害、抢先击杀、准备以后收益互相争预算 | S3 |
| 加牌或跳过 | 加入弱牌可能稀释关键牌的抽到机会；看见奖励不等于必须拿 | S1 确认选择是否加入；S2、S4 解释跳过与牌组密度 |
| 升级、删牌、恢复 | 让牌更好、让好牌更常出现、保命，会竞争稀缺机会 | S4 |
| 选路线与遗物 | 精英奖励强但战斗难；事件未必纯利；遗物能改变组合价值 | S1、S2 |

多数敌人的下一步意图会预告，使玩家能用有限资源规划；这不代表完全没有随机或所有情况都能精确预测。常规战斗依赖能量、抽牌/弃牌、格挡、攻击与状态互动；这里仅采用二手资料支持的概念，不把其逐条回合顺序当已验证代码。[S3]

### 3. 局内构筑与永久成长是两种东西

一代每局重新从初始牌组发展，本局拿到的整套强力牌组/遗物，不是下一局直接带进去的永久装备仓库。跨局保留的是解锁内容与可选挑战进度，玩家对敌人、组合和路线的理解也增长。[S4、S5]

**我们的主循环不同：**第一款游戏是稳定生产、装备升级、矿场解锁和小镇长期建设。当前规则明确保留永久装备和区域进度。若整体换成“每趟从零构筑”，就会削弱工坊为探索提供装备的意义。这是设计适配性判断，不是说卡牌玩法本身不适合经营题材。

### 4. 独立实现时需要的结构

如果研究完整卡牌玩法，至少会需要牌库/手牌/弃牌/消耗区、能量与状态、效果结算顺序、敌人意图、节点地图、奖励编辑和本局存档。

对当前项目，没必要建设整套卡牌系统才能借到它的优点。可以只研究：

- `RouteChoice`：房间/分叉之间的高层风险关系。
- `EncounterDefinition`：普通房、精英房、资源房、事件房、补给节点的明确用途。
- `ChoiceOutcome`：互斥选项与真实成本，不给“全都要”的默认答案。
- `RunState`：本趟选择、已访问房间、一次性奖励与随机种子。

这些是本报告建议的项目结构，不是原游戏类名；未实现。

## 与当前地牢的具体对照

本轮现场核对第一款游戏 `AGENTS.md` 和 `docs/01-game-outline.md`，HEAD 为 `d818b56`，并读取已有夜勤人研究入口。不恢复旧归档设定、不改现有规则。

**当前已定：**夜间矿区用房间网格、进房刷怪/清房、矿脉采矿、武器素材与 Boss 进度；移动、翻滚、近远武器与料理回血，和潜水共用操作；装备与矿场是长期成长。

用户口述的“夜情人”在当前文档中对应**夜勤人（Moonlighter）**。其官方定位就是动作角色扮演、地牢战利品与商店经营，不是卡牌游戏。[S6]

| 层 | 目前适合保留的东西 | 从尖塔可研究的东西 | 要不要整体换 |
| --- | --- | --- | --- |
| 战斗手感 | 移动、翻滚、武器，水下复用操作 | 明确招式预告、可读的危险窗口 | 不换成抽牌与回合制 |
| 房间结构 | 物理房间网格、矿区模板、连通校验 | 高层路线取舍，普通/危险/资源节点的区别 | 不必取消网格，分叉可直接体现在房间里 |
| 收获 | 矿物、区域素材、加工和售卖 | 高回报附代价、少量互斥奖励 | 可以局部加深，不能让随机增益取代矿物主产出 |
| 成长 | 工坊装备、首通、矿场永久解锁 | 少量固定的本趟效果 | 只能叠在永久成长上，不能擅自清零装备 |
| 玩家节奏 | 晚间探索服务于整天经营计划 | 让玩家有意识选择路线与撤离 | 需测一趟能否匹配营业与日结，不照搬尖塔完整时长 |

### 建议采用顺序

**第一优先：把路线变成真正的选择。**

例如同一个分叉，“有更多普通矿脉但要绕路”与“精英守着额外区域素材”，玩家能根据血量、背包、缺什么原料做决定。普通矿物仍按当前解锁规则产出；不新增卡牌、技能条或装备词条海。具体提示方式待用户确认，不要求把地图换成尖塔同款节点 UI。

**第二优先：少量互斥资源决策。**

先考虑“消耗已有料理继续深探，还是撤离保住收获”等现成资源取舍；事件房若增加，也先控制数量。不要同时加回血药水、全新休息资源、复杂永久角色天赋——当前规则的回血来源是料理。

**第三优先、非首个切片必须：有限本趟效果。**

可研究预设且可解释的几个效果，让同样的动作操作有变化；不能复制商业遗物的名字、文本、图标，也不要做无限随机词条。它会增加战斗平衡、提示与存档工作，先把既定“获取—加工—卖货—升级—首通”切片跑通，再比较是否值得加。

## 什么时候才值得真的替换地牢

以下是**改变项目方向的条件**，不是本轮已做的决定：

- 目标体验改成慢思考、低操作压力，玩家更想研究牌组而不是移动闪避。
- 不再要求潜水与地牢共用同一套战斗操作，愿意维护两种战斗与 UI。
- 明确重新解释工坊装备、料理和矿物在卡牌构筑中的作用。
- 愿意新增大量原创卡牌、状态、效果交互、敌人意图、触控卡牌界面与组合测试。

若主要原因是“动作地牢怕无聊”，更经济的验证通常是先试房间分叉、招式可读性、差异化怪物和资源需求；但这不保证一定比改卡牌好玩。若玩家测试表明动作操作本身不受欢迎，应该重新讨论大纲，而非因为已写文档就拒绝改变。

## 复现路径

**独立最小验证建议，未实际运行。**

1. 基线先跑通已定动作地牢和真实矿物掉落，不同时引入卡牌战斗。
2. 在同一小地图做两个版本：线性房间序列；一处分叉、风险与资源差异明确的序列。
3. 武器、怪物基础数值和总资源规模先保持可比，避免“新版单纯奖励更多”造成假结论。
4. 观察玩家是否看懂风险、是否会因血量/背包/原料需求换路线、是否觉得绕路只是拖时间。
5. 验证读档不重抽房间和奖励、返回不重复领取、分叉都可达目标、固定种子可复现。
6. 再决定加事件或本趟效果。若真要比较卡牌与动作，另做隔离试验，并明确它不代表正式引擎与安卓验收。

## 适用场景与限制

《杀戮尖塔》非常适合**一局内组合成长与连续决策**；我们可借它的决策设计，不必借它的战斗载体。卡牌化可能降低部分动作操作压力，但会增加卡牌文本阅读、效果顺序理解和组合调试；不能直接宣传为“省美术、开发一定更简单”。

玩法参考不构成商业源码或素材授权；公开介绍没有开源许可。工程改动量是定性分析，尚无工期估算、实机性能或玩家偏好证据。

- 没有试玩这两种新方案，不能断言卡牌或混合方案一定更有趣。
- 房间分叉提示、特殊房、有限本趟效果均是建议；**未更换夜勤人参照、未修改 G6/G7/G8 或大纲/Skill**。
