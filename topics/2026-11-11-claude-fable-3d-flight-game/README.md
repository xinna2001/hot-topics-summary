## 技术实现

### 1. 模型、开发 Agent 与游戏运行时是三层

**Fable 5.2 是语言模型，不是游戏引擎，也不是这个视频中未命名的视频生成器。** 官方型号为 `claude-fable-5-2`，支持文字、图像输入和文字输出，适合复杂、多步骤技术任务。模型通常生成或修改程序与素材描述；游戏的画面与交互仍由具体引擎、浏览器或应用运行时执行。[S2–S3]

若通过 Claude Code 开发，工具层负责读工程、改文件、运行命令和检查结果。这提供了“需求 → 代码修改 → 运行 → 反馈 → 再修改”的闭环。原视频没有展示工具界面，因此 **Claude Code 只是可采用的官方开发路径，并未确认是作者使用的工具**。[S4–S5]

本案例可提炼的工作流是：

```text
人确定玩法与美术方向
    ↓
视频生成器制作视觉参考（原帖宣称；产品未注明）
    ↓
提取参考图，描述色彩、空间、镜头与飞行感觉
    ↓
编程模型 + 开发工具修改工程
    ↓
游戏运行时渲染场景并处理输入
    ↓
试玩、截图或日志反馈 → 多轮修正
```

视频模型的画面可以帮助沟通审美，并不自动提供可碰撞地形、角色控制器、可收集物或游戏源码；实际转换步骤在原帖中缺失。上图后半部分是根据官方工具能力整理的可行路径，不是对原作者开发轨迹的还原。

| 尾迹、水花、收集物 | 粒子池/复用几何体；依据高度与速度触发；收集碰撞更新 HUD 和提示 | 本报告设计建议；未确认作者资源与实现 |

关键源码入口：

- `src/objects/InstancedMesh.js:19–24,50–67`：大量同类网格与逐实例变换/颜色。[S9]
- `examples/jsm/objects/Water.js:86–88,153–203,238–337`：镜像相机、反射 render target、动态法线与反射混合。[S10]

## 模型与成本口径

### 已核实的模型规格

官方 API 型号 `claude-fable-5-2`，上下文上限 1M tokens，最大同步输出 128K tokens，API 默认 effort 为 `high`，adaptive thinking 常开。Claude Code/应用默认 effort 与 API 不同，不能把它们混作统一默认。官方定位是长任务和困难推理；这不是针对本游戏的成功率或耗时保证。[S2–S3,S5]

### 不把订阅额度比例当作 API 账单

- 原帖的 **200 美元/月** 是订阅金额，**20%** 的分母没有说明：可能涉及整体、Fable 单独或其他周期额度。没有 usage 截图与周期起止，无法核对。
- 当前官方 **Ultra 为 200 美元/月**，原 Max 20x 用户自动迁移；Ultra 有全模型周额度与独立 Fable 周额度，已验证账号不设五小时上限。这里只用于解释当前计量规则，**不据此替作者确认账号方案或其 20% 分母**。[S6]
- `200 × 20% = 40` 只是算术结果，不是该项目的新增现金支出、按量账单或可复用报价。
- Fable 5.2 标准 API 单价：输入每百万 tokens **8 美元**，输出每百万 tokens **40 美元**。有缓存、Batch、Fast 等不同口径，不能套用单一价格还原订阅成本。[S2]
- 不含这些调整时，API 基础估算为：`8 × 输入百万 tokens + 40 × 输出百万 tokens`。本次未调用 Fable API，没有本案例 token 数，不生成伪精确账单。
- 视频参考生成费用、人力、已有工程/资产、托管及后续修复都未披露，不能默认为零。

### 准备与最小步骤

1. **先锁玩法，不先追全部画质。** 最小原型：一座岛、一个可控飞行角色、地面/海面、少量收集点、跟随镜头。明确移动、转向、升降、重置与碰撞规则。
2. **准备有权使用的视觉参考。** 从自有或获授权的视频参考提取少量帧，写出色彩、花海密度、飞行高度、镜头倾斜与光照方向。视频/图片是审美输入，不是已完成的游戏资产。
3. **选择运行时。** 浏览器方案可固定已发布 `three@0.187.0`，保留 lockfile；先搭渲染循环、输入和角色控制，再加实例化花海、海面与天空。研究引用的 dev commit 不应被当作与 release 字节完全一致的证明。[S8–S12]
4. **选择编程 Agent 与模型。** 如果使用已经安装且已授权的 Claude Code，Fable 5.2 需 v2.1.321 或以上；Anthropic 直连可显式选择固定型号，不依赖浮动别名。[S5]

   ```bash
   # 以下仅是复现者在自己的授权环境中使用的示例，本次未执行
   claude --version
   claude --model claude-fable-5-2
   ```

   第三方网关或云提供方需要确认对应部署 ID 与模型权限。不要把代理 URL 相同当成模型相同，也不默认同意额外 usage credits。[S5]

5. **分阶段验收。** 顺序为控制/碰撞 → 地图/收集 → 水与花海 → 镜头与音效 → 质量档和发布。每轮提供失败条件、截图或日志，保留模型修改前后的工程，防止漂亮画面掩盖坏交互。
6. **发布后回读真实页面。** 在目标浏览器和设备检查资源加载、输入、尺寸变化和帧时间。只发送实际可访问且确认为本工程的地址。

| 项目 | 可执行验收口径 |
