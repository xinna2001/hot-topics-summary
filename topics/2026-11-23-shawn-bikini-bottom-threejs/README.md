### 可行实现参考，不是恢复的作者源码

Three.js 的官方 `Water.js` 实现的是**平面反射水面**：多个随时间偏移的法线纹理采样、镜像相机/反射 render target、光照与 Fresnel 风格反射混合。它不是完整流体仿真，也不能单独等价于海底焦散、体积光和整个城市系统。[S4]

官方 ocean 示例组合 `Water`、`Sky`、太阳方向和环境贴图，可作为海面最小实验。原片水下可见光束和地面亮纹，但仅凭画面不能确定是贴图、程序 shader、后处理还是实际光学模拟。[S1、S4]

`GLTFLoader` 可以作为导入外部 glTF/GLB 资产的入口；代码也有 Draco、KTX2 与 Meshopt 解码配置接口。是否压缩模型、采用何种格式、是否存在动画剪辑，要看实际文件，不能从“Hi3D + Three.js”几个词推出。[S4]
