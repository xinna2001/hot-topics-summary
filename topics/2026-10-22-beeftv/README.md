# BeefTV：本地 AI 视频画布与短剧工作流

收录日期：2026-10-22

最近核实：2026-10-22（Asia/Shanghai）

研究状态：产品、工作流和当前许可已核实；模型生成与原视频未实测

## 一句话结论

BeefTV 把分镜、图片、视频、音频、模型渠道和异步任务组织在本地优先的创作画布中。它当前采用分范围的 Source Available 许可，不能把整个最新版仓库继续视为无额外限制的 MIT 开源项目。[S1][S3]

本轮读取当前仓库 README、功能说明、快速开始、工作流编译源码和 LICENSE；没有构建桌面程序或调用生成模型。

## 技术实现

1. React 前端画布通过节点与连线表达素材、创作上下文和处理关系。
2. Go 后端统一管理项目、资产、任务和模型配置，Wails 把它们组合为桌面工作区。
3. Provider/插件适配不同模型协议；生成时按用户选定渠道访问外部服务。
4. 素材节点和生成记录构成可复用工作流；后端编译时校验持久资源、输出类型、输入绑定和选定模型。
5. 生成结果成为可再次编辑、引用和迭代的资源，分镜与短剧入口在同一工作台中组织。[S1][S2][S4][S5]

## 复现路径

**基于当前说明整理，未构建或运行。**

1. 下载适合系统架构的官方桌面版，或按 QUICKSTART 的 Go 1.25、Bun、Wails 组件要求构建固定版本。
2. 建立测试项目，先加入文本和一张现有图片，确认保存和重新打开。
3. 添加自己的模型渠道，以一个最小图片或视频任务验证生成、状态、预览与失败提示。
4. 把素材和生成节点连成小流程，验收输入引用、输出格式和重新执行结果。
5. 导出或迁移工作区，核对素材与任务历史是否仍可用。

成功标准是工作区保存可恢复、生成任务真正完成、节点关系和媒体结果正确。“本地优先”不意味着所有模型离线运行。当前快速开始还说明 Mac 包未完成 Apple 签名和公证；安装时依官方和系统流程处理。[S4]

## 适用场景与限制

适合需要统一管理分镜、参考素材、模型生成和短剧迭代的创作者。成片质量、角色一致性、失败重试与费用由具体模型及流程决定，软件本身不保证一键高质量成片。商业发行软件或向外提供托管时，当前许可范围是实际决策条件。
